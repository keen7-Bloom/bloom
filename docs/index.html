Fair questions,

guest@bloom — zsh
➜ bloom --price
free while in beta. if we ever charge, it'll be for optional extras — the core app stays free and nothing you have gets taken away.
➜ bloom --intel-mac
yes. native x86_64 build, not emulation. macOS 11+. a 2015 MacBook deserves a live wallpaper that doesn't melt it.
➜ bloom --battery
paused on battery by default (you can override). plugged in, a 1080p loop costs about as much as a muted video in a hidden tab.
➜ bloom --wallpapers
yours. any mp4/webm on disk. a small starter pack ships in the box so first launch isn't lonely.
➜ bloom --why-trust-you
don't — verify. open source, and every release ships an Activity Monitor screenshot from real hardware. receipts > promises.
